# Public history

This repository preserves all 104 development commits through the selected source snapshot. Original author and committer names, both timestamps and timezone offsets, commit messages and parent topology are retained. Author and committer addresses use the GitHub noreply address for Senya01. Commit IDs therefore differ from the private originals.

Every revision is a source-only projection. Original game files, generated game tables, private research captures and build/operational reports are omitted throughout history. 56 commits whose selected tree is unchanged are deliberately retained so the development sequence and dates are not silently collapsed. Some original messages describe private evidence that is intentionally absent here. The private repository remains unchanged.

Selected source bytes are preserved, except that one hard-coded local translation-neighbour path was removed from six historical versions of the Windows startup source. Existing source-preview header generator and scoped license files retain their original introduction/change sequence at their public paths. Historical versions are not all claimed to build without their own user-supplied inputs.

A separate current publication commit adds this explanation, the MIT license for new original project code, public README/manifest/ignore files and external generated-table build options. It is not backdated. No original game data or private Git parent/object store is included.
